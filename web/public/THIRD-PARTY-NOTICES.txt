2. Bundled npm packages and Rust crates  --  their own licenses
================================================================================

The web UI bundles npm packages (React, MapLibre GL, Leaflet, xterm.js,
Recharts and their dependencies), and the Pi binaries link Rust crates. Each
keeps its own license. web/public/THIRD-PARTY-NOTICES.txt lists every one with
its license text, after this NOTICE. tools/third-party-notices.py generates it
from web/package-lock.json and Cargo.lock, and CI fails when it is out of
date. The web UI serves it at /THIRD-PARTY-NOTICES.txt, linked from Settings >
System > Resources.

Files under web/node_modules/ are installed by npm and are not part of this
project's source; build from package.json / package-lock.json instead.

3. Vendored xfuse XFS parser  --  BSD 2-Clause License
================================================================================

The files under crates/disk_reader/src/xfs/ (except fs.rs, reader.rs,
shim.rs, and volume.rs, which are original Sentry-USB-Rusty work) are
vendored from the xfuse project, version 0.7.1
(https://github.com/KhaledEmaraDev/xfuse), Copyright (c) 2021 Khaled Emara,
and remain under the BSD 2-Clause License reproduced in each file's header.
Local modifications: fuser/libc/nix dependencies replaced with a portability
shim (see shim.rs) and the FUSE server replaced with a path-based read-only
API (fs.rs).

================================================================================
4. Vendored exfat crate  --  MIT License
================================================================================

The files under crates/disk_reader/vendor/exfat/ are vendored from the
exfat crate, version 0.1.0 (https://github.com/obhq/exfat), Copyright (c)
Obliteration contributors, MIT License (see COPYING in that directory).
Local modifications: unused (deleted) directory entries are skipped per the
exFAT specification instead of ending the directory scan, and benign
primary entries (e.g. Volume GUID) are ignored instead of failing — both
required to read Tesla-written filesystems.

web/scripts/icons/overrides are from Google's
Material Symbols icon set (outlined style, weight 400), obtained via the
@material-symbols/svg-400 package (https://github.com/marella/material-symbols),

SVG so the UI ships no icon font and makes no external request. Local
modifications: `battery_full_alt` is mirrored horizontally so the battery
terminal faces right.

7. Raspberry Pi OS in the SD card images  --  GPL and other licenses
================================================================================

The Sentry USB SD card images (sentryusb-raspberry-pi-image.img.xz, on stable
releases and listed in Raspberry Pi Imager) are built on Raspberry Pi OS Lite
(64-bit), plus the Debian packages that install-pi.sh adds. Those programs
keep their own licenses, many of them the GNU General Public License. Each
image is built from the Raspberry Pi OS release named in Raspberry Pi's Imager
OS list on the day it was built.

Source code for these programs:

  Linux kernel and Raspberry Pi firmware
    https://github.com/raspberrypi/linux
    https://github.com/raspberrypi/firmware
  Raspberry Pi OS packages
    https://archive.raspberrypi.com/debian/  (source packages)
  Debian packages
    https://deb.debian.org/debian/  (source packages)
    https://sources.debian.org/

Written offer: for at least three years after we last distribute an image,
anyone may email info@sentry-six.com to get the complete corresponding source
code for the GPL-licensed programs in that image, on a physical medium or as
a download, for no more than the cost of providing it.
